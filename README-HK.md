# 文字檔建立器

[English](README-EN.md) | [简体中文](README-EN.md) | 繁体中文

一個可以用快速鍵快速建立新文字檔的自製小工具。 為建立新文字檔的操作綁定了快速鍵，以及開啟(系統內建)記事本的快速鍵。以便快速建立文字檔。

## 使用

> 該軟體為系統匣形式 啟動後，按對應快速鍵即可執行對應的操作。可在軟體設定中自訂快速鍵。（除了 Ctrl+Alt+V 和 Ctrl+Shift+V 還有包含Windows鍵的快速鍵綁定不上）

### 預設快速鍵（v1.1.0）

[**Ctrl**]+[**Shift**]+[**空格**] > 建立文字檔
[**Ctrl**]+[**Shift**]+[**F**] > 開啟記事本

## 注意事項

- 一直按著的話，會持續觸發：連續建立很多個文字檔 / 開啟很多個記事本視窗。
