\# 文本文档创建器

\[English](README-EN.md) 简体中文



一个可以用快捷键快速创建新建文本文档的自制小工具。



为创建新建文本文档的操作绑定了快捷键，以及打开(系统自带)记事本的快捷键。以便快速创建文本文档。



\## 使用

> 该软件目前仅托盘形式。可以设置开机自启动。



启动后，按对应快捷键即可执行对应的操作。



\#

\[\*\*Windows\*\*]+\[\*\*F\*\*] - \*\*创建文本文档\*\*



\[\*\*Windows\*\*]+\[\*\*J\*\*] - \*\*打开记事本\*\*
