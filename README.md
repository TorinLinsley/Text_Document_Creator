# 文本文档创建器

[English](README-EN.md) 简体中文



一个可以用快捷键快速创建新建文本文档的自制小工具。



为创建新建文本文档的操作绑定了快捷键，以及打开(系统自带)记事本的快捷键。以便快速创建文本文档。



## 使用

> 该软件为托盘形式

启动后，按对应快捷键即可执行对应的操作。可在软件设置中自定义快捷键。（除了 Ctrl+Alt+V 和 Ctrl+Shift+V 还有带Windows键的快捷键绑定不上）

### 默认快捷键（v1.1.0）
[**Ctrl**]+[**Shift**]+[**空格**] > 创建文本文档

[**Ctrl**]+[**Shift**]+[**F**] > 打开记事本

## 注意事项
- 一直按住的话，会持续触发：连续创建很多个，打开很多个记事本窗口。
